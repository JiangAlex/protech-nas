# Intel Atom D2550 NAS 硬體規格

## CPU — Intel Atom D2550

| 項目 | 規格 |
|------|------|
| 核心/執行緒 | 2C / 4T |
| 基礎頻率 | 1.86 GHz |
| TDP | 10W |
| 製程 | 32nm |
| 快取 | 1MB L2 |
| 內顯 | Intel GMA 3650 |
| 支援記憶體 | DDR3-1066 |
| 最大記憶體 | 4GB |
| 指令集 | 64-bit |

## 功耗估算

| 狀態 | 功耗 |
|------|------|
| 待機 (HDD 休眠) | ~10W |
| 一般使用 | ~20W |
| 滿載 | ~30W |

## 效能注意事項

- CPU 效能有限，避免同時跑太多重量級容器
- 4GB RAM 限制：建議 Docker 容器控制在 3-5 個輕量服務
- 無硬體轉碼（GMA 3650 不支援 QSV）
- SMB 傳輸瓶頸可能在 CPU 而非網路
